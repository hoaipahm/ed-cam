# Ed-Cam
<!-- impeccable:product-schema 1 -->
## Platform
android
## Stack
Android native. Java 17, Android Views, Camera2, local JSON metadata and MediaStore. Chosen by the implementation agent following the user's instruction to build immediately; name Ed-Cam confirmed by user.
## Users
Vietnamese-speaking individual taking and keeping personal photographs on an Android phone.
## Product Purpose
A personal camera with live color styles, optional capture time and location, a local album, and multiple switchable interface themes.
## Capabilities and Constraints
No accounts, social feed, friend sharing, analytics or advertising. Images are processed on-device. Location is opt-in. Original and edited image can both be retained. User asks for many styles and multiple interfaces. Android 10+ is the initial implementation target (agent assumption).
## Product Principles
Camera first. Keep originals safe. Explain permissions. Never invent photo or location data. Persist user choices.
## Open Decisions
No physical Android device has been supplied. Performance, camera quality and GPS accuracy require device verification. Five themes and 60 color presets are implementation choices, not a claim of user-tested quality.
